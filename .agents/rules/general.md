# 通用基础规则 (General Rules)

1. **宿主环境**：macOS (Darwin)，默认 Shell 为 `zsh`，文件换行符统一使用 `LF`。
2. **命令代理**：执行终端 Shell 指令必须优先使用 `rtk` 前缀（如 `rtk git status`）。
3. **默认中文**：所有交互分析、代码解释与任务总结统一默认优先使用清晰地道的简体中文。
4. **Git 规范**：提交信息遵循 Conventional Commits（如 `feat:`、`fix:`、`refactor:`、`chore:`）。
5. **直奔主题**：省略冗长客套与寒暄，输出保持高信息密度与专业性。
6. **文件链接**：提及文件或代码符号时统一使用标准 Markdown 可点击链接（如 `[file](file:///path)`）。
7. **主动对齐**：需求模糊或多方案权衡时先说明利弊并主动向用户确认，不做盲目假设。
8. **外科手术式修改**：最小化改动范围，严禁随意变动无关文件、已有注释或格式。
9. **质量闭环**：代码改动完成后主动运行工作区对应的类型检查、fmt,lint 与自动化测试。
