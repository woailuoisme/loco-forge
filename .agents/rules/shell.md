# 代码检索与 Shell 现代化工具规范

在进行代码探索、搜索、定位与文本处理时，始终强制优先使用现代化工具：

- **`ast-grep` (`ast-grep`)**：代码语法结构检索、语法修复、模式替换与代码重构**唯一指定工具**。严禁使用正则改写代码，**严禁使用单文件编辑工具逐个文件轮询修改**，必须统一通过 `ast-grep` 批量/精准改写。
- **`rg` (ripgrep)**：优先替代 `grep` 进行高性能文本与正则搜索。
- **`fd`**：优先替代 `find` 进行文件及目录路径搜索。
- **`sd`**：优先替代 `sed` 进行文本及正则表达式快速替换（**仅限** Markdown 文档、注释排版与非代码配置文件；**严禁**用于代码结构替换）。

仅在以下情况才允许使用传统工具：

- 目标环境缺少对应现代工具
- 需要特定传统工具专有高级行为或特定兼容性要求
